# Engineering Principles

This directory contains the engineering principles that serve as the evaluation
framework for all decision proposals.

## Contents

- [**principles.md**](principles.md) — The 10 engineering principles. These are
  the foundation against which RFCs and technical proposals are evaluated.

## How Principles Are Used

1. **AI Review** — Each AI persona evaluates proposals against these principles
   from their specialized lens. The principles provide a shared vocabulary for
   reasoning about trade-offs.
2. **Decision Making** — When trade-offs arise, principles provide a structured
   framework for reasoning about which path to take.
3. **Onboarding** — New engineers read these to understand how the organization
   thinks about technical decisions.

## Changing Principles

Principles are living documents. To propose a change, submit an RFC. Changing a
principle is a cross-team decision and follows the standard RFC process.
